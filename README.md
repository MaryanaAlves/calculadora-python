# Calculadora em Python

Calculadora com interface gráfica desenvolvida em Python, utilizando a biblioteca Tkinter, que permite realizar operações matemáticas por meio de uma interface visual com botões interativos.

## Funcionalidades

- Interface gráfica com botões interativos
- Operações matemáticas por meio dos botões da calculadora
- Exibição dos valores e resultados na interface
- Personalização visual com cores, fontes e elementos gráficos
- Interação com o usuário por meio de comandos associados aos botões

## Tecnologias

- Python
- Tkinter
